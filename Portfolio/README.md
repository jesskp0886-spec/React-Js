## ✨ Features

- Clean, dark, developer-terminal-inspired UI
- Fully responsive across mobile, tablet, and desktop
- Scrolling status ticker with live availability info
- Sections: Hero, About, Experience, Projects, Skills, Achievements, Contact
- No external images or stock photos — pure code-driven design
- Fast builds and instant dev reload with Vite

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite
- **Styling:** CSS3 (custom design tokens, no framework)
- **Fonts:** Space Grotesk, Inter, IBM Plex Mono

## 📂 Project Structure

```
jiya-portfolio/
├── src/
│   ├── components/     # One component per section (Hero, About, Projects, etc.)
│   ├── data.js          # All content (profile, projects, skills) in one place
│   ├── styles.css        # Design tokens + all styling
│   └── App.jsx
├── public/
├── index.html
└── package.json
```

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/your-username/jiya-portfolio.git
cd jiya-portfolio

# 2. Install dependencies
npm install

# 3. Run the development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview the production build
npm run preview
```
